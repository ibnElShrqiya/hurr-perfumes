# حُرّ HUR — ملاحظات النسخة المحسّنة

## إعداد Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `hurr-perfumes-main` (إذا كان المشروع داخل مجلد بهذا الاسم في المستودع)
- أضف `VITE_SUPABASE_URL` وواحدًا فقط من `VITE_SUPABASE_ANON_KEY` أو `VITE_SUPABASE_PUBLISHABLE_KEY` إلى بيئة Production.

## التغييرات
- تحسين استجابة رأس الموقع والأقسام على الهواتف ومنع تمدد الصفحة أفقيًا.
- جعل جداول الإدارة قابلة للتمرير أفقيًا داخل الحاوية على الشاشات الضيقة.
- حذف مجلد `dist` القديم من حزمة المصدر حتى يُنشأ بناء جديد عند النشر.
- إضافة fallback لـ SPA عبر `public/_redirects` كي تعمل المسارات مثل `/admin` عند فتحها مباشرة.
- مواءمة تحويل المنتج مع مخطط قاعدة البيانات الحالي: لا يتم إرسال `bottle_style` في عمليات الكتابة لأنه غير موجود في الجدول المنشور، مع الاحتفاظ بقيمة عرض افتراضية عند عدم وجود العمود.
- إبقاء كتالوج المنتجات فارغًا افتراضيًا؛ لا توجد أسعار أو منتجات تجريبية مضافة محليًا.
- نقل نسخة مرجعية من SQL إلى `supabase/schema-reference.sql` وعدم نشرها كملف عام داخل `public`.

## ملاحظات قبل الإطلاق
- لا تُشغّل ملف schema المرجعي كاملًا فوق قاعدة بيانات إنتاجية قائمة دون مراجعة؛ لا حاجة إلى إعادة إنشاء الجداول الحالية.
- اختبر تسجيل الدخول، إضافة منتج حقيقي، إنشاء طلب، وتتبعه بعد نشر Production.
