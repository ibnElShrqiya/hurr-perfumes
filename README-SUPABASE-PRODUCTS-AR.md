# توافق جدول المنتجات في Supabase

تمت مواءمة `src/lib/supabase.ts` وعمليات إضافة/تعديل المنتجات مع الأعمدة الموجودة حاليًا في `public.products`:

- `id` (UUID يولّده Supabase)
- `name`, `slug`, `description`, `price`, `image_url`, `stock`, `is_active`, `created_at`, `updated_at`

لا يحتاج هذا الإصلاح إلى تنفيذ SQL أو إضافة أعمدة أو حذف بيانات. تُحفظ الصورة الأولى من قائمة الصور في `image_url`، ويُشتق وضع المنتج من `is_active` والمخزون. الحقول غير الموجودة في المخطط الحالي، مثل التصنيف والخصومات والتقييمات والنوتات العطرية، لا تُرسل إلى قاعدة البيانات؛ وتظهر بقيم افتراضية في الواجهة. حاليًا تُعرض المنتجات المسترجعة ضمن تصنيف «للجنسين» لأن الجدول لا يحتوي عمود تصنيف.

**مهم:** لا تطبّق `supabase/schema-reference.sql` على قاعدة البيانات الحالية دون مراجعة مستقلة؛ فهو مخطط مرجعي أقدم يحتوي بنية أوسع مختلفة عن جدولك الحالي.
