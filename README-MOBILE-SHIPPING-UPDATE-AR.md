# تحديث تجربة الهاتف والشحن المجاني – حُرّ

## التغييرات
- أصبح حد الشحن المجاني 1000 جنيه مصري في حسابات المتجر والملفات المرجعية لقاعدة البيانات.
- خيارات المحافظة في صفحة إتمام الطلب تعرض اسم المحافظة فقط؛ رسوم الشحن تظل محسوبة وتظهر في ملخص الطلب.
- عناصر التنقل في الترويسة تعيد المستخدم إلى واجهة المتجر عند الحاجة، ثم تفتح القسم المحدد مثل الرئيسية أو العروض الحصرية.
- تحسينات responsive للهاتف: تقليل مساحة صورة المنتج الرئيسية، تقليل الحشو والمسافات، وبطاقات منتجات أكثر إحكامًا مع عرض عمودين على الشاشات الصغيرة.

## مهم قبل النشر
إذا كانت قاعدة بيانات Supabase الحية تستخدم الدالة `public.create_store_order` الموجودة مسبقًا، شغّل ملف الترحيل التالي مرة واحدة من SQL Editor في Supabase:

`supabase/migrations/202610290001_free_shipping_threshold_1000.sql`

هذا ضروري لأن تعديل ملفات SQL داخل المشروع وحده لا يغيّر الدالة المنشورة بالفعل في قاعدة البيانات.

## التحقق
تعذر تشغيل بناء Vite في بيئة العمل هذه لأن تنزيل بعض الحزم من npm registry فشل بسبب تعذر الاتصال بالشبكة. شغّل `npm ci` ثم `npm run build` في بيئة التطوير أو أثناء بناء Cloudflare Pages للتأكد من نجاح البناء قبل النشر.
